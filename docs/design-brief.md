# 3栋51# 建筑漫游：设计与实现简报

## 1. 一句话概念

在真实户型尺度中呈现一栋可进入、可上下楼的六层住宅：一楼门厅，二至五楼冷静现代，六楼温馨美式轻奢。

## 2. 交付与验收清单

- 参数化 Blender 工程：六层结构、1F 独立大堂、2F–6F 住宅内装、屋顶、真实门窗洞口、双跑楼梯、电梯井、阳台和近场场地。
- 可复现入口：根目录 `build.py`；无头 Blender 生成 `.blend`、建筑 GLB、碰撞 GLB、人物 GLB 与检查图。
- 楼层分配不可混淆：1F 大堂；5F 按三张 GTA 截图适配黑白灰现代装修与家具；2F–4F 复制 5F 主题；6F 按内装视频做美式轻奢。
- 6F 地面必须是用户指定的米白高抛光大理石、深棕金色双线及卷草花拼花，不使用木地板。
- 6F 保留奶白布艺沙发、黑胡桃木家具、白色乳胶漆与美式护墙板、水晶灯、花艺窗帘和 3000K 暖光，禁止因 GTA 参考改成黑皮沙发。
- PDF 实际房间、外轮廓和交通核优先于最初文字；两户不强制镜像。
- 模型发布目标：Draco 几何压缩；KTX2 纹理优先使用 Adreno 可解码的 ASTC 4×4，不能把 UASTC 当成 ASTC。
- 浏览器交付：Edit3D 可编辑项目 + 共用模型的独立 Vite/Three.js Pages 应用。
- 漫游：第三/第一人称、胶囊碰撞、重力、跳跃、可走楼梯、门洞可通过、镜头防穿墙。
- 双端输入：WASD/鼠标/Shift/空格/滚轮/V；触屏摇杆、右侧滑动、跳跃、横屏提示和全屏。
- UI：标题“3栋51# 建筑漫游”、按钮“点击进入”、1F–6F 传送、小地图、绿蓝状态条。
- 建筑巡场提供连续多机位镜头，自由漫游提供实时控制；所有控制提示在 Play 首帧可见。
- 性能目标：总三角面不超过 200 万，同屏不超过 150 万，DPR≤2；Adreno 8XX 的 60 fps 仅为目标，真机未测前不得宣称达标。

## 4. 尺度与楼层

- 外轮廓 17.20 × 14.90 m；Blender 南向为 −Y，Three.js 南向为 +Z，导出时由 glTF 转换。
- 1F 大堂层高 3.60 m；2F 地面标高 3.60 m；2F–6F 每层高 3.00 m；屋顶标高 18.60 m。
- 外墙 0.24 m，内墙 0.12 m；室内门洞约 0.90 × 2.10 m。
- 交通核：楼梯约 2.60 × 5.40 m，电梯井约 1.80 × 2.20 m。
- PDF 标注：左户套内 111.89 ㎡，右户 117.71 ㎡，本层建筑面积 256.28 ㎡。

## 6. 参考特征到实时实现

| 参考特征 | 实现决策 |
|---|---|
| 5F GTA 黑色低靠背沙发 | 黑色皮革、低底座、分体坐垫、贵妃位与金属细脚；2F–4F 复制 |
| 5F 玻璃金属茶几、圆顶灯 | 双层玻璃、黑色细框、白色圆顶灯与黑色吊线 |
| 5F 现代空间层次 | 黑白橱柜、灰色餐椅、竖向格栅、壁炉、抽象画、望远镜与绿植 |
| 6F 米白大理石拼花 | 高抛光米白石材、深棕金色边界与卷草花纹理；法线和粗糙度独立控制 |
| 6F 奶白布艺沙发 | 圆角分体坐垫、细法线织物、非金属、高粗糙度；禁止黑皮革 |
| 6F 美式护墙板 | 白色底板、顶线、踢脚和分格线条，上部为白色乳胶漆 |
| 6F 黑胡桃木家具 | 独立木纹材质和合理 UV；木柜、桌椅、床架不全黑金属化 |
| 6F 水晶灯、花艺与双层窗帘 | 金属灯架、透射晶体、波形帘布、纱帘、白花瓶、浅粉花材与绿叶 |
| 3000K 暖光与游戏级后期 | 6F 暖色灯带和筒灯；实时端采用 ACES、PMREM、软阴影与低强度后期 |

源纹理按主墙 4K、其余 2K 准备；为控制实时显存，交付版主墙等颜色纹理降为 1K、法线／ARM 为 512，卷草花拼花保留 1600 × 1800。只使用用户素材或 CC0 资源，并在 `docs/credits.md` 记录来源与许可。

## 7. 模型组织与性能

- Blender 集合：`SITE`、`SHELL`、`F01`…`F06`、`CORE`、`ROOF`、`LIGHTS`。
- 5F 建完整现代主题，2F–4F 只复制主题新增对象与碰撞体，不重复墙板或建筑结构。
- 6F 独立美式主题，不使用现代楼层的黑皮革或现代挂画。
- 按“楼层 × 材质 × 静态/可编辑”合批；5F、6F 左右户的主要沙发和主卧床保留独立对象与编辑入口，共注册 8 个可编辑对象。
- 墙体真实开洞；玻璃窗与窗帘分层；共面装饰层至少错开 1 mm，避免闪烁。
- 漫游按当前楼层显示室内细节，外壳和场地保留；碰撞使用独立低模。
- `collision.glb` 包含墙盒、家具盒、楼板与楼梯坡面；门洞为空，移动求解与视觉模型分离。

## 8. 人物与动画

- 程序化连续蒙皮低多边形人物，深色卫衣、长裤、运动鞋；22 骨，少于 2 万三角面。
- `idle`、`walk`、`run`、`jump` 四个 glTF 动作；Three.js `AnimationMixer` 管理，切换 crossFade 0.20 s。
- 胶囊底点与脚底一致；跳跃由垂直速度驱动，动作方向与位移方向对齐，按速度选动画，避免滑步。

## 9. 场景、交互与编辑项

- “建筑巡场”：完整建筑、近场环境和连续多机位镜头，默认展示外立面及关键室内空间。
- “自由漫游”：角色、输入、HUD 和碰撞；空间在 Play 首帧即可移动，退出时清理监听、动画与 DOM。
- 可编辑参数：太阳时段、室内灯光强度、行走/跑步速度、镜头距离、楼层显示、5F/6F 关键家具位置与材质。
- 通过 SDK 注册对象、材质和参数；SDK 拥有 Edit3D 渲染器，嵌入场景不自建 renderer/composer。
- 独立 Pages 应用负责 WebGPU 优先、WebGL2 回退和 EffectComposer，避免与 Edit3D 生命周期冲突。

## 10. 环境与渲染分工

- Blender：几何、UV、PBR 材质、蒙皮、动作、静态合批、导出与检查渲染。
- Three.js：模型加载、楼层管理、动画、控制、碰撞、交互、UI、实时环境与性能统计。
- 室外使用物理天空/环境反射、铺装、人行道、草地、灌木、乔木和低矮周边体量，不把建筑放在空白平面上。
- 实时渲染不承诺离线路径追踪效果；以参考的材质层次、空间关系和灯光阅读性为目标。

## 11. 验证门槛

1. 新 Blender 进程加载保存的 `.blend`，核对楼层、外轮廓、对象、材质和动画。
2. 渲染外观、5F 现代客厅、6F 美式客厅和餐厅检查图并实际查看；至少完成一轮“截图→缺陷→修复→同机位复查”。
3. GLB 重导入，检查法线、尺度、材质、骨骼、动画和三角面；压缩前后均验证。
4. 检查实际材质名、`sceneLint()`、编辑参数、撤销和保存恢复；检查场景切换与资源释放。
5. 浏览器验证开始界面、键鼠、触屏模拟、传送、碰撞、楼梯、门洞、镜头和响应式布局。
6. 记录构建产物大小、面数、draw call 与实际测试环境；未做的真机、WebGPU 或线上验证明确标注。
