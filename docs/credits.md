# 素材来源与许可

## 用户提供的项目参考

以下素材由用户提供，用于本项目的户型、空间、风格或材质参考：

- `3栋51#谢小亮方案图.pdf`：户型、门窗、交通核与外轮廓。
- 三张 GTA 风格截图：5F 黑白灰现代装修与家具；2F–4F 复制该主题，并作为实时材质与光影参考。
- 美式轻奢内装视频及抽帧：6F 奶白布艺、护墙板、黑胡桃木、水晶灯、花艺窗帘与暖光。
- 两张米白大理石拼花图片：6F 最终地面、深棕金色双线和卷草花拼花。

这些素材统一标记为**用户提供**。本清单不推定其采用 CC0，也不替用户声明额外再分发许可。

## Poly Haven 纹理

使用的 Poly Haven 纹理包括：

- `wood_floor`
- `black_walnut_veneer_01`
- `marble_01`
- `cotton_jersey`
- `rectangular_paving`

Poly Haven 纹理按 CC0 发布。每个颜色、法线和 ARM 文件的直接来源 URL、字节数与 MD5 均记录在 `docs/texture-manifest.json`，没有猜测来源地址。

## 程序化与其他资源

- 建筑、家具、碰撞体、人物和动画由本项目 Blender／Python 管线生成。
- 卷草花大理石拼花由用户提供参考经本项目处理为运行纹理。
- Three.js、Draco、KTX2／Basis 与 Edit3D SDK 各自保留其原始许可和版权声明；本清单不重新授权这些依赖。
- Blender 源文件及 GLB 中的纹理已内嵌，运行时不依赖外部素材网站。
